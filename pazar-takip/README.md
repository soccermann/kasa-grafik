# Pazar taraması takibi
- tara.py: Pazar günü umit liste taraması (mod seçimi: genişlik >= %20 GÜÇ, < %20 TEPKİ). Kurallar dosyanın başında.
- degerlendir.py: Cuma kapanış sonrası açık listelerin performansı; takip süresi dolan listeler sonuclar.csv'ye yazılır.
- listeler/: her Pazar'ın listesi (YYYY-MM-DD.json).
- umit_liste.txt: TradingView "umit liste" kopyası (18.10.2026). Liste değişirse güncelleyin.
Kurallar 2019-2026 geriye dönük testinden (503 hisse, İş Yatırım verisi) gelir. Yatırım tavsiyesi değildir.
